# 导出课表

Bell 可以将已采用方案中的课表保存为 Excel `.xlsx` 或 CSV。支持行政班、教学班、教师、教室、学生、学科和年级七种查看方式；每次导出一个选定对象的完整课表。

## 从桌面导出

1. 打开项目，在方案列表中打开需要的方案。如果结果还在运行历史中，先将它采用为独立方案。
2. 在方案课表中选择查看方式和对象，例如“教师 → 张老师”或“学生 → 某位学生”。
3. 点击 **导出 Excel** 或 **导出 CSV**。
4. 在系统保存窗口中选择文件夹和新文件名。默认名称带有方案与课表版本，便于区分。
5. 看到“已保存”后，在所选位置打开文件。

导出包含该对象的全部课次，不受屏幕当前页限制。连堂课在课程清单中占一行，在周课表中占用所有对应课节，后续课节标有“续”。同一时段的多门课程分行显示。

Bell 只保存新文件，已有同名文件不会被覆盖。选择其他文件名即可重新导出。取消保存窗口不会保存文件；如果选择保存后出现“导出结果未确认”，先检查所选位置，避免仅凭通信提示判断文件是否存在。

## 选择格式

| 格式 | 适合用途 | 内容 |
| --- | --- | --- |
| Excel `.xlsx` | 教务核对、教师查看、进一步整理与打印 | 来源说明、周课表、课程清单三个工作表 |
| CSV | 与其他工具交换课程明细 | UTF-8 编码、带 BOM 的完整课程清单 |

Excel 中的周课表设置为 A4 横向，按纸张宽度分页，较长课表可继续到后续页。打印前请在所用表格软件中检查预览；纸张、字体和打印机设置可能影响实际版面。课程清单支持筛选，包含课程、班级、教师、教室、人数和课次标识。

Excel 按文本保存编号和版本，保留前导零及长数字。若用 Excel 打开 CSV，请在导入时把编号和版本列指定为文本，避免表格软件自动转换。CSV 中可能被识别为公式的文本会加保护前缀。

导出文件用于查看与交换，不是学校数据的导入模板。没有课程的对象会得到只有表头的课程清单，周课表显示无课程，不会补造课程。

## 版本与范围

每次导出前，Bell 都会重新检查方案数据和完整课表，并核对所打开的方案、课表版本。版本已变化时需重新打开方案再导出。

项目数据更新后，旧方案仍可以导出。Excel 的来源说明和 CSV 的课程行记录方案保存的历史来源，并注明导出检查时的来源状态；空 CSV 只有表头。导出不会把旧方案自动套用到新数据上，也不会修改项目或方案。

当前不支持一键批量导出所有学生、教师或班级，也不直接生成 PDF、HTML 或 ICS。每次导出的内容和文件有容量限制；若 Excel 文字过长、无法完整排版，可改用 CSV。请保留原项目数据库，导出文件不能替代项目备份。

## 使用 CLI

`scenario-timetable` 可以列出方案中的对象及其 ID，`export-scenario` 将所选对象保存为新文件，两者都需要明确的方案和课表版本：

```sh
target/rust-1.88.0/debug/class-schedule-cli scenario-timetable --help
target/rust-1.88.0/debug/class-schedule-cli export-scenario --help
```

导出命令使用 `--view`、`--entity-id` 选择对象，`--format xlsx` 或 `--format csv` 指定格式，`--output` 指定文件。目标文件夹需要已存在。CLI 的构建和数据库操作见 [开发指南](development.md)。
